# Blocks
An assortment of scripts for some quality of life when using i3blocks.
Most depend on their respective systemd unit to work correctly, but some may work
without their helper scripts if interval polling is all that is needed instead of RT signals.

## Requirements
### Afk.sh
- xorg-xset

### Bluetooth.sh
- bluez-utils

### Network.sh
- iwd

### Spotify.sh
- [helper script](https://github.com/rseld/scripts/tree/main/spotify)

### Temps.sh
- nvidia-settings

### Volume.sh
- PipeWire
- Wireplumber 0.5+
- [helper script](https://github.com/rseld/scripts/tree/main/wireplumber) (optional)
